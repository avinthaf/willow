# Problems when working with AI Agents

The AI agent does not know me, especially if it’s a newly created agent. It doesn’t know my level of technical expertise, my proficiency in the current programming language I’m working with, my understanding of the current project, any cognitive impairments that I have, my learning style...etc.

I can’t share my AI agent with someone else. If I want to onboard a new developer into a project I've been working on, unless I have thoroughly documented all of my learnings, I can’t properly onboard them. Also their AI agent doesn’t have the context that mine does. If I could give my AI agent long-term memory and have that memory accessible by other agents, this could potentially solve the problem? Maybe?

Big walls of technical text. The AI agent does not know how to speak to me because it doesn’t know me. It assumes that I have the same level of intelligence and working memory that it has. Also it speaks to me like it’s writing a book. It needs to be a little bit more casual so I can understand it better.

My skills are atrophying. I feel like just a meat proxy most of the time, just giving the AI agent logs and asking it to figure things out or just giving it some instructions and asking it to write code. I’m someone that learns by doing. I don't know how to ‘do’ when I have an AI agent and I don’t know if I can ‘do’ because now AI speed is the expected delivery speed.

The AI agent does not know my organizational policies. Unless I specify coding standards and such, it’ll do its own thing. I have to specify this every time.
